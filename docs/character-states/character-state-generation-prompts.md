# Character-state generation record

**Method:** OpenAI built-in image generation  
**Mode:** Reference-guided generation / identity-preserving continuation  
**Art direction:** Living Gouache  
**Output role:** High-resolution equipment and identity concepts, not animation sprites

The prompts below are the final prompt set used for the approved state images. Each state used the immediately previous cumulative image as its primary identity reference, the approved stripped body where useful, and the approved Cinderbound anchor only as a long-term destination.

## State 0 — Bare Chassis

```text
Use case: identity-preserve
Asset type: corrected game character progression concept, State 0 — Bare Chassis
Input images: Image 1 is the edit target stripped-body design. Image 2 is the approved final-form proportion anchor.
Primary request: Change only the body proportions of Image 1 so the stripped character has the same compact identity and total proportion system as Image 2: exactly about 3.25 heads tall, a noticeably larger square head relative to the body, a much shorter torso, shorter upper and lower legs, shorter arms, wider practical hands, slightly broader shoulder span, and a low sturdy center of gravity. Keep the feet and joint forms compact. The result must feel like the same small utility automaton before armor, not a tall humanoid skeleton.
Preserve exactly from Image 1: fully stripped equipment state, square head design, cyan face, core cage, exposed collar ring, dark iron frame, cable routing language, bronze fasteners, neutral three-quarter view facing right, neutral stance, warm-gray studio background, lighting, rendering style, and absence of all equipment.
Constraints: change only proportions; do not add armor, cloth, belt, pack, shoulder plates, chest plate, weapons, holsters, tools, labels, text, UI, logo, watermark, extra views, or extra character. Full body centered with generous padding.
```
